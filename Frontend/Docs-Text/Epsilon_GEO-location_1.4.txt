1 Description  Page:   1-1  Date:   19.Sep.2018  Rev:   1.3  1.1 Geo Location Feature  Epsilon GEO Location feature allows operator to see GPS coordinates of the target at any time. At all times GPS coordinate (longitude, latitude) of the target and slant range from the target to the camera are indicated on the screen.  Video screen with GEO information  Complete set of Geo Location feature benefits include: a. Operator can see the GPS coordinates [LAT ; LON] of the target at which the gimbal is pointing at any time; b. Operator can see the Slant Range [SR] to the target at which the gimbal is pointing at any time; c. Operator can input GPS coordinates of the object of interest and automatically steer the gimbal towards it; d. Operator can input the list of predefined targets by entering its corresponding GPS coordinates and automatically steer the gimbal towards each one of them when necessary. 2 GEO Settings  Page:   2-1  Date:   19.Sep.2018  Rev:   1.3  2.1 General  Epsilon GEO features settings allows user to configure various parameters such as GPS antenna location relative to internal INS module, Laser Range Finder mode, Pan/Tilt offsets and Digital Elevation mode. GEO settings are located under Epsilon Settings menu.  GEO settings main window  2.2 GPS Antenna Setup  GPS antennas location is very important for GPS/INS module accuracy and needs to be configured every time when GPS antennas are reinstalled. Epsilon has two options for GPS/INS internal module: 1) moving platform with one GPS antenna; 2) stationary platform with two GPS antennas.  IMPORTANT: if Epsilon with GEO-location feature is installed on stationary platform such as air balloon, permanent mast or other stationary platform, you will not be able to calibrate GPS antenna and this feature will not work.  GPS antennas can be set up through Epsilon software menu by clicking:   Settings   >   Geo   and clicking on “ GPS Antenna Settings ”.  GPS antenna settings  Epsilon GEO-location RT LTA Systems Ltd RT LTA Systems Ltd

3 Moving Map Software Overlay  Page:   3-3  Date:   19.Sep.2018  Rev:   1.3  3.4 Add Raster Map  The Epsilon software supports TIF (TIFF) format georeferenced raster map images. This allows user to create custom maps or overlays to display on the Epsilon map. The world file also must be supplied with raster image to provide necessary GEO information. It is a separate text file, which can be created with any text editors (Notepad++). The world file must be with the same name and TIFW format as shown in Figure 12.  Note : The rendering speed depends on the performance of the computer, the more detailed (the larger) the TIFF file is, the more time can be occupied to render it. To generate world file manually, create a text file with 6 lines described in table below:  Text file Line   Description   Units   Example  1   Longitudinal scale of the image   Deg/pixel   0.00102459 2   Not used, needs to be 0   -   0 3   Not used, needs to be 0   -   0 4   Latitudinal scale of the image   Deg/pixel   0.00144868 5   Longitude of the image top-left corner   Decimal degrees   23.292606 6   Latitude of the image top-left corner   Decimal degrees   56.335875  1st line  Vertical scale of the map. Subtract longitude of the top of the image of the map from the coordinates of the bottom of the map image and divide it by number of vertical pixels of the image.  Example (see the attached map) Line 1 = (Longitude_A – Longitude_B)/Image height in pixels. (23.2942.55 – 23.2946.48) / 3904 = 0.00102459  Vertical scale of the man  Epsilon GEO-location RT LTA Systems Ltd RT LTA Systems Ltd
