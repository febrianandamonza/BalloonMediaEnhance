1. Introduction  The Crowd counting model uses a deep learning neural network to estimate the  number of people appearing in an image with high accuracy and high processing  speed.  The neural network contains many convolution layers to understand images. It takes  an image (or a video) as input and it outputs a density map of the human head.  “ Figure 1 ” illustrates an example of the output of a processed input image. The  brighter color on the output map indicates the higher density of the human head.  Therefore, the estimated number of people appearing in the crowd is obtained based  on the generated density map. For example, the estimated counting value is “512” for  the below image.
